# DIOS — 스킬 보드

AI 에이전트가 쓰는 스킬을 한 곳에 두고, 눌러서 붙이고, 한글로 읽고, 다른 컴퓨터와 맞추는 Windows 앱입니다.

Claude, Codex, Cursor, Grok처럼 에이전트마다 스킬 폴더가 따로 있으면, 같은 글을 여러 번 복사하고 어느 게 최신인지 잊게 됩니다. DIOS는 스킬 파일을 한 곳에만 두고, 각 에이전트 폴더에는 바로가기만 걸어 줍니다. 글을 한 번 고치면 붙어 있는 에이전트가 모두 같은 글을 봅니다.

## 할 수 있는 일

**API 키 관리** — 프로젝트마다 어떤 플랫폼의 키를 쓰는지 한 곳에서 봅니다. **폴더 골라서 키 찾기**를 누르면 폴더를 하나 또는 여러 개 고를 수 있고, 고른 폴더 안의 `.env` 파일에서 키를 찾아 보여 줍니다. **새 프로젝트 찾기**는 이 컴퓨터를 기본으로 보고, SSH·WSL은 직접 고른 곳만 봅니다. 새로 생긴 접속 장소는 켜기 전에는 들어가지 않습니다. Git 워크트리는 빼며, 고른 키만 저장합니다. 화면에는 그 장소 이름을 그대로 붙입니다. 찾은 키는 승인 전에는 저장하지 않습니다. **훑는 폴더** 카드에는 폴더마다 어디서 왔는지(직접 고름 · 연동한 프로젝트 · 흔히 쓰는 폴더)와 마지막으로 훑었을 때 설정 파일이 몇 개였고 키가 몇 개 나왔는지가 한 줄씩 남습니다. 폴더가 사라졌으면 빨간 점으로 알려 주고, **이 폴더만 훑기**·**열기**·**빼기**를 줄마다 바로 누를 수 있습니다. 결과 글도 "폴더 1개"가 아니라 `"Projects" 폴더를 훑었는데…`처럼 폴더 이름을 말합니다.

**정리** — 개발 환경을 쓰다 보면 쌓이는 것들을 한 화면에서 말로 보여 줍니다. 첫 줄이 "저장 안 한 수정이 있는 프로젝트 3곳, 창 없이 켜져 있는 프로그램 2개, 혼자 도는 예약 작업 2개, 비울 수 있는 자리 약 6GB예요"처럼 오늘 볼 것을 한 문장으로 말합니다. 카드는 네 가지입니다. **저장 안 한 수정**은 훑는 폴더(API 키 관리와 같은 폴더) 안의 git 프로젝트마다 저장 안 한 수정·올리지 않은 기록·따로 꺼내 둔 작업 폴더(worktree)가 몇 개인지 보여 주고, 사라진 작업 폴더 기록은 **사라진 기록 지우기**로 정리합니다(파일은 건드리지 않습니다). **창 없이 켜져 있는 프로그램**은 vite·Next·python http.server·Ollama·터널처럼 터미널에서 켜 두고 잊은 개발 서버를 찾아 몇 시간째 켜져 있는지, 어느 폴더에서 돌고 있는지 보여 주고 **끄기**를 누르면 한 번 더 물어본 뒤 끕니다. 같은 포트를 두 프로그램이 같이 쓰고 있거나, 한 폴더에서 개발 서버가 두 번 켜져 있으면 그 이유를 한 문장으로 보여 줍니다. 하루 넘게 켜진 프로그램이나 이렇게 겹친 것이 있으면 왼쪽 메뉴 **정리** 옆에 숫자가 붙습니다. **자리만 차지하는 폴더**는 `node_modules`·빌드 결과물·가상 환경·임시 저장 폴더 중 20MB가 넘는 것을 크기와 함께 보여 주고, 그 프로젝트를 마지막으로 손댄 때가 한 달이 넘었으면 라임 점이 켜집니다. **휴지통으로**를 누르면 한 번 더 물어본 뒤 휴지통으로 보내므로 되돌릴 수 있습니다(임시 파일 폴더는 통째로 보내지 않습니다). **혼자 도는 예약 작업**은 cron·systemd 타이머·Windows 작업 스케줄러에 걸린 것을 "매일 9시", "5분마다"처럼 읽어 주고 보기만 합니다. 운영체제가 기본으로 넣어 둔 작업은 뺍니다. 열기·끄기·휴지통은 모두 이 화면이 방금 보여 준 항목에만 작동합니다.

**지금 할 일 (지금은 쉬는 중)** — 목록이 스스로 정리되지 않아 잠시 보류했습니다. 첫 화면과 왼쪽 메뉴에서 빠지고 **더 보기** 안에 **보류** 표시로 남아 있으며, **설정 → 지금 할 일 화면 켜기**로 언제든 다시 켤 수 있습니다. 켜면 아래처럼 동작합니다. MainPC의 할 일 목록을 읽습니다. Aside에게 말할 일과 직접 하실 일이 카드로 나오고, 새 일이 오면 화면이 알아서 바뀝니다. **Aside에게 줄 글 복사**를 누르면 짧은 말 대신 할 일 글 전체가 복사되어 Aside 창에 붙여 넣을 수 있습니다. 직접 하실 일은 **안내 글 복사**와 붙여 넣을 명령이 있습니다. 결과를 카드에 붙여 넣으면 끝난 일로 옮겨지고 시킨 에이전트에게도 전해집니다. 붙여 넣은 결과가 길면 끝난 일 목록에는 한 줄 요약이 보이고, **결과 전체 보기**를 열면 붙여 넣은 글 전체가 그대로 나옵니다. 안 할 일은 지우면 다시 오지 않습니다.

**프로젝트 홈** — 고른 프로젝트에서 기다리는 지금 할 일이 몇 개인지 맨 위에 나오고, **지금 할 일 보러 가기**로 바로 갑니다. 단계·백업·요청서 같은 예전 화면은 아래 **예전 화면 보기**를 열면 나옵니다.

**프로젝트 홈의 스킬** — 고른 프로젝트 이름이 Agent Relay 프로젝트와 같으면, 그 프로젝트에 붙은 스킬이 나옵니다. **끄기**를 누르면 그 프로젝트에서만 빠지고, **켜기**를 누르면 계획·만들기·검사에 다시 붙습니다. 스킬 글은 그대로입니다. 꺼 둔 스킬도 목록에 남아서 다시 켤 수 있습니다. **다른 스킬 붙이기**를 열면 공용 폴더에 있지만 이 프로젝트에는 없는 스킬을 찾아서 바로 붙일 수 있습니다. **켜 둔 스킬 글 바탕화면에 저장**을 누르면 바탕화면 `DIOS-프로젝트-스킬` 안에 프로젝트 이름 폴더가 생기고, 그 안에 Aside에게 줄 검토 안내 한 장과 켜 둔 스킬 글이 번호 순으로 들어갑니다. DIOS 안에서 유료 AI를 부르지는 않습니다.

**변경사항** — 스킬을 켜고 끈 기록이 "JuPlan에 founder-ux 붙임 · 3분 전"처럼 한 줄씩 남습니다. 프로젝트 홈, 스킬 라이브러리, 스킬 보드 어디서 바꿔도 같은 목록에 옵니다. 가장 최근 기록 옆의 **되돌리기**를 누르면 그 스킬이 바로 전 상태로 돌아가고, 되돌린 것도 기록에 남습니다. 작업 폴더를 연결해 두었으면 **바뀐 파일 보기**로 새 파일·고친 파일·지운 파일 수를 보고, **시험 돌리기**로 통과했는지 봅니다. Git 원문과 경로는 **원문 보기** 안에만 있습니다.

**프로젝트 홈의 이번 주 그래프** — 오늘 한 일 한 줄 아래에 지난 7일 그래프가 나옵니다. 날마다 Claude Code와 Codex에 얼마나 썼는지 막대로, Cursor 대화는 숫자로 보이고, 이번 주 합계와 어느 에이전트가 몇 %인지 한 문장으로 적습니다. 사용량 화면의 **이번 주 프로젝트별**에는 같은 그래프가 프로젝트마다 나란히, 같은 기준 높이로 나옵니다.

**Agent Relay 프로젝트 그대로 만들기** — 프로젝트 홈에 프로젝트가 없거나, 고른 프로젝트 이름이 Agent Relay에 없으면 Agent Relay 프로젝트 목록이 단추로 나옵니다. 하나를 누르면 이름이 같은 홈이 만들어져서 스킬을 바로 켜고 끌 수 있습니다.

**스킬 라이브러리에서 프로젝트에 붙이기** — 공용 폴더 스킬 카드의 **프로젝트에 붙이기**를 열면 Agent Relay 프로젝트마다 붙었는지 보이고, **붙이기**·**끄기**로 바로 바꿉니다.

**사용량** — Claude Code와 Codex가 이 컴퓨터(그리고 SSH로 연결된 컴퓨터)에 남긴 기록을 읽어 오늘·이번 주·이번 달에 얼마나 썼는지 보여 줍니다. 프로젝트 이름을 누르면 그 프로젝트 홈으로 갑니다. 홈이 아직 없으면 Agent Relay 프로젝트 목록에서 같은 이름으로 바로 만들 수 있습니다. 구독으로 쓰는 도구는 "API로 썼다면 약 N달러"로 나오고, OpenRouter 키는 실제 쓴 돈이 나옵니다. OpenAI와 Anthropic 키는 사이트로 가는 버튼이 있습니다. 넘으면 알려 줄 금액을 카드마다 정할 수 있고, 화면을 열 때만 읽어서 뒤에서 돌아가는 것은 없습니다. 프로젝트 홈에는 고른 프로젝트의 오늘 한 일이 한 줄로 나옵니다. 정해 둔 금액을 넘거나 스킬 글이 공용 폴더와 다르면, 켜진 뒤 한 번 알림이 옵니다.

**스킬별로 보기** — 왼쪽에서 스킬을 고르면 오른쪽에 설명, 붙은 에이전트, 같이 쓰는 스킬, 글이 같이 나옵니다.

**눌러서 붙이기** — 에이전트 이름을 누르면 붙고, 다시 누르면 빠집니다. 빼도 스킬 글은 남습니다.

**에이전트별로 보기** — 에이전트마다 카드가 있습니다. 스킬을 카드 위로 끌어다 놓아도 붙습니다. 매 대화 안내도 여기서 켜고 끕니다.

![에이전트별 보기](docs/media/agents-view.png)

**번역본 보기** — 영어 스킬을 한글로 읽습니다. 번역은 이 컴퓨터 안의 무료 모델이 하고, 스킬 글은 밖으로 나가지 않습니다. 문단마다 옮기고, 같은 말을 반복하거나 중국어가 섞이거나 한 줄이 비정상적으로 길어지면 그 결과는 저장하지 않습니다. 예전 번역이 그래서 이상하면 번역본을 다시 열 때 새로 만듭니다. 스킬 라이브러리의 한글 설명은 앱을 켜 두면 하나씩 미리 만들어 둡니다. **한글 설명 지금 만들기**를 누르면 남은 것을 바로 만들고, **한글 설명 멈추기**로 멈출 수 있습니다. 한 번 만든 글은 저장되어 다음부터 바로 열립니다. 영어 원문이 바뀌면 그때만 다시 번역합니다. 에이전트에게는 항상 영어 원문이 갑니다.

![번역본 보기](docs/media/korean-copy.png)

**글 고치기와 이전 글** — 앱 안에서 고칩니다. 고치기 전 글은 남아서 되돌릴 수 있습니다. 밖에서 파일이 바뀌면 노란 **바뀜** 표시와 바뀐 줄이 보입니다.

**휴지통** — 지운 스킬은 휴지통에 들어갑니다. 다시 꺼내면 원래 붙어 있던 곳에 붙습니다.

**처음 열 때** — 대표님 컴퓨터가 아니면, 처음 한 번은 이 컴퓨터에서 찾은 에이전트와 스킬 수를 보여 줍니다. 그다음부터는 **스킬 보드**가 먼저 나옵니다. 설정에서 지금 할 일을 켜 두면 그 화면이 먼저 나옵니다.

**화면 디자인** — JU 브랜드(JU Signal) 공통 규칙을 따릅니다. 검정 바탕, 종이색 글자, 라임은 켜진 상태·신호점·주요 단추에만 씁니다. 바탕에는 점(픽셀) 무늬가 깔려 있고, 마우스를 가져다 대면 그 주변 점이 밝아지며 가장 가까운 몇 개만 라임으로 켜집니다. 가끔 신호 하나가 한 줄을 따라 지나갑니다. 켤 때는 점이 나타나고 → 모이고 → 자리 잡는 순서로 움직입니다. Windows의 "애니메이션 효과 줄이기"를 켜 두면 움직임 없이 점 무늬만 남습니다. 왼쪽 위 DIOS 표시는 점 글자 "D" 안에 선반 세 줄(스킬 정리)과 라임 신호점 하나입니다. 2026-10-02에 대표님이 이 디자인으로 진행하라고 승인했습니다.

**스킬 라이브러리** — 이 컴퓨터에 있는 스킬을 한 곳에서 봅니다. 한 폴더에만 있는 스킬은 **한 곳에만 있는 N개 모으기**로 공용 폴더에 넣고 준비된 에이전트에 붙입니다. Cursor가 기본으로 넣어 둔 스킬은 그대로 둡니다. 원래 폴더는 지우지 않습니다. 공용 폴더, Claude·Codex·Cursor 같은 에이전트 폴더, Cursor 기본 제공, Hermes 폴더를 모두 모아 이름 하나에 카드 하나로 보여 줍니다. 카드에는 누가 만들었는지, 언제 생겼는지, 어디에 붙어 있는지가 나오고 이번 주에 생긴 것에는 **새로 생김** 표시가 붙습니다. GitHub 주소나 SKILL.md 주소를 붙여 넣고 **다운로드하기**를 누르면 바로 받아서 준비된 에이전트에 붙습니다. 저장소 하나에 스킬이 여럿이면 골라서 받습니다. 폴더에서 추가하거나 다른 컴퓨터에 있고 여기엔 없는 스킬을 가져올 수도 있습니다. 한 폴더에만 있는 스킬은 **공용 폴더에 넣고 붙이기**로 다른 에이전트도 쓰게 만듭니다.

**컴퓨터끼리 비교** — 이 컴퓨터, WSL, SSH로 연결된 컴퓨터의 스킬을 한 표로 봅니다. 글이 다르면 맞추고, 없는 곳에는 보내고, 이쪽에 없으면 가져옵니다. 글이 같으면 덮어쓰지 않습니다.

## 설치

1. [Releases](https://github.com/ju0o/Dios/releases/latest)에서 `DIOS-Setup.exe`를 받습니다.
2. 실행합니다. 서명이 없는 파일이라 Windows가 막으면 **추가 정보 → 실행**을 누릅니다.
3. 열리면 첫 화면이 **스킬 보드**입니다. API 키는 왼쪽 **API 키 관리**에서 봅니다. 지금 할 일은 **설정**에서 켜면 다시 첫 화면이 됩니다.

새 버전은 앱 왼쪽 아래 **업데이트 확인**으로 받습니다. 새 버전이 있으면 버튼이 노란색이 되고, 받은 뒤 다시 시작하면 적용됩니다. 켜고 나서 한 번만 조용히 확인하고, 그 밖에는 버튼을 눌렀을 때만 봅니다. 새 버전으로 처음 켜면 화면 위에 "0.2.2로 새로워졌어요 · 무엇이 바뀌었는지" 한 줄이 나오고, **알겠어요**를 누르면 사라집니다. 그 글은 저장소의 `release-notes.md`에서 오고, GitHub 릴리스 설명에도 같은 글이 붙습니다.

번역본을 보려면 [Ollama](https://ollama.com)가 필요합니다. 없을 때는 설치 안내가 나오고, 모델은 `qwen2.5:7b`(약 5GB)를 한 번 받습니다. 받는 동안은 작은 모델 `qwen2.5:3b`로 먼저 번역하고, 큰 모델이 오면 다시 번역합니다. 결제나 API 키는 필요 없습니다.

지금은 Windows 설치 파일만 있습니다.

## 직접 만들기

```bash
git clone https://github.com/ju0o/Dios.git
cd Dios
npm install
npm run dev
npm run build
```

`npm run build` 결과는 `release/DIOS-Setup.exe`입니다. GitHub에 올리는 설치 파일도 같은 이름이고, 버전 태그(`v0.2.6` 같은 것)를 푸시하면 Windows에서 만들어져 Releases에 붙습니다.

## 알아 둘 것

- 스킬 파일은 그 컴퓨터 안에만 있습니다. DIOS가 외부 서버로 보내지 않습니다.
- 번역은 무료 모델이고, 매끄럽지 않은 문장이 남을 수 있습니다.
- 코드는 이 저장소에서 볼 수 있습니다. 라이선스는 아직 정하지 않았습니다. 재배포와 상업적 이용은 정해진 뒤에 문의해 주세요.
